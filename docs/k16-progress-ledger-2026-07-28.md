# K16 Pisa 锦标赛项目：当前成果总账

截至 2026-07-28

## 结论先行

**K16 的全局问题仍然开放。**目前既没有找到一张通过独立验证的 K16 Pisa 锦标赛，也没有完成覆盖全空间的 UNSAT 证明。

但是，我们已经把问题从“任意 16 点锦标赛”压缩成了两个很窄的方向：

1. **可分解候选：**任何非平凡模只能有大小 2 或 3；大小至少 4 的模已全部排除。
2. **全局本原候选：**零 margin 点只剩两类尾部，分别是  
   \((d,b)=(7,1), B\ge16\) 或 \((d,b)=(6,3), B\ge20\)。

这里 \(d=d^+(v)\)，\(b(v)\) 是从 \(v\) 两步仍到不了的入邻居数，\(B=\sum_v b(v)\)。

```text
可能的 K16 witness
├─ 可分解
│  ├─ 含大小 >=4 的模：已排除
│  └─ 只含大小 2/3 的模：只剩 h14_p00、h15_p00 两个关键对角盒
└─ 本原（无非平凡模）
   └─ 仍开放，但必须落在两个高阻塞 endpoint 尾部
```

## 证据等级

本总账只使用四种标签：

| 标签 | 含义 |
|---|---|
| **理论证明** | 不依赖本次求解器运行的数学推导 |
| **精确计算封闭** | 求解器返回 `INFEASIBLE/UNSAT`，且该任务的分割覆盖可核对 |
| **经验支持** | 随机、局部搜索或指定构造族没有命中，只能帮助画像 |
| **UNKNOWN** | 时间耗尽或任务未覆盖完成；不产生排除结论 |

GitHub 的绿色勾只表示作业流程成功完成。数学上只有结果 JSON 中的 `UNSAT` 才封闭对应盒子；`UNKNOWN` 即使作业结束，也仍然开放。

## 一、已建立的结构工具

### 1. blocker 恒等式

在 16 点锦标赛中，对每个顶点 \(v\)：

\[
m(v)=|N_2^+(v)|-|N_1^+(v)|
    =15-2d^+(v)-b(v).
\]

因此

\[
\sum_v m(v)=-\sum_v b(v).
\]

若 \(v\) 是零 margin 点，则 \(b(v)=15-2d^+(v)\)。结合已用的最低出度界 \(d^+(v)\ge2\)，零点只有六种：

\[
(d,b)\in\{(7,1),(6,3),(5,5),(4,7),(3,9),(2,11)\}.
\]

这六类给出了完整的终局分划，而不是启发式猜测。

### 2. 近正则孪生对定理

近正则 Pisa 锦标赛若存在，低度点与覆盖它的高度点被迫组成孪生有序对；缩并后得到正则商锦标赛。因此近正则 Pisa 锦标赛只可能出现在

\[
n\equiv2\pmod4.
\]

对 \(n=16\)，度谱

\[
7^8\,8^8
\]

被理论排除，不再需要 SAT 重跑。

### 3. 字典积的 margin 可加性

设

\[
T=Q[R_1,\ldots,R_h]
\]

是锦标赛的替换/字典积，纤维 \(R_P\) 的大小为权 \(t_P\)。对 \(v\in R_P\)：

\[
m_T(v)=m^{\,w}_Q(P)+m_{R_P}(v),
\]

其中 \(m^{\,w}_Q(P)\) 是以纤维大小为权的商图 margin。

这条恒等式同时提供：

- **构造方向：**可行的加权商图配上传递纤维，会生成一张 Pisa 锦标赛；
- **分解方向：**可分解的 Pisa 锦标赛会给出一个可行加权强商图。

所以“按商阶 \(h\) 搜索”不是只找某种漂亮构造，而是精确处理所有可分解候选。

### 4. 两个零类的安全性

当前精确加权模型要求至少两个零加权-margin 类。使用的原始定理把 dominated vertex 定义为出度为 0 的点；强连通的传递纤维展开图没有这种点，因此 Havet–Thomassé 的两 Seymour 顶点结论可以应用。

未证明的“至少三个零类”从未作为 UNSAT 约束使用。

主参考：[Havet–Thomassé, *Median Orders of Tournaments*](https://www.math.ru.nl/OpenGraphProblems/TimV/%5BHavet%20and%20Thomass%C3%A9%5D%20Median%20Orders%20of%20Tournaments.pdf)。

## 二、全局 K16 endpoint 已封闭到哪里

### 已完整封闭

- 零点分支 \((2,11),(3,9),(4,7),(5,5)\)；
- \((6,3)\) 分支中 \(B\le19\) 的所有层；
- \((7,1)\) 分支中 \(B\le15\) 的所有层；
- 近正则度谱 \(7^8 8^8\)；
- THIN-A 度谱 \(6^1 7^6 8^9\)；
- THIN-B 度谱 \(7^9 8^6 9^1\)；
- 一个固定标准 K14 Pisa 底座的全部二点扩张。

### 尚未封闭

全局 endpoint 现在精确剩下：

\[
\boxed{(d,b)=(7,1),\ B\ge16}
\]

或

\[
\boxed{(d,b)=(6,3),\ B\ge20}.
\]

早先的粗层名称共有六个：

- \(d=7\)：\(B=16,17,18,19,\ge20\)；
- \(d=6\)：\(B\ge20\)。

后续 v7.1–v15 对这些层做了大量不相交细分，但还没有把任何剩余粗层的全部子叶清空。

### 2. \(h=10\)：11 个权多重集全部 UNSAT

权和 16 分成 10 个正整数共有 11 个无序多重集；[正式矩阵 run 30234142140](https://github.com/lieoric/k16-pisa-terminal-search/actions/runs/30234142140) 的 11 个 \(h=10\) 盒子均得到精确 `UNSAT`。因此商阶 \(h=3,\ldots,10\) 已全部封闭。

### 3. 单大纤维对角线

若 K16 有一个大小为 \(m\) 的模，把它缩为一个商点、其余点作为单点纤维，就得到

\[
h=17-m,\qquad (m,1^{16-m}).
\]

已经精确封闭：

| 模大小 \(m\) | 对应盒 | 状态 |
|---:|---|---|
| \(m\ge7\) | \(h\le10\) 全体阶梯 | UNSAT |
| 6 | `h11_p00=(6,1^10)` | UNSAT |
| 5 | `h12_p00=(5,1^11)` | UNSAT |
| 4 | `h13_p00=(4,1^12)` | UNSAT |

所以：

\[
\boxed{\text{任何 K16 Pisa witness 都没有大小至少 4 的模。}}
\]

最新的 \(h=13\) 关闭由两个连续 run 完成：

- 初始 cube run [30250854456](https://github.com/lieoric/k16-pisa-terminal-search/actions/runs/30250854456)：13 个权位置中 1 个直接 UNSAT，其余 12 个细分成 144 个“第二零类”切片；143 个 UNSAT，只留下 `h13_p00_a000_z02`。
- 最终语义分割 run [30296663274](https://github.com/lieoric/k16-pisa-terminal-search/actions/runs/30296663274)：按零点度数、第二零类的加权出度/阻塞权、唯一 blocker 的加权出度继续做互斥完备分割，最终 6/6 度数块全部关闭。

最后一个困难子块在 841.884 秒后返回 `INFEASIBLE`，搜索了 1,921,859 个分支并产生 851,086 个冲突。归档证据见 [h13-p00-closure-github-30296663274.json](../evidence/h13-p00-closure-github-30296663274.json)。

### 4. 现在只剩两个可分解关键盒

要排除全部可分解 witness，只需再关闭：

1. `h14_p00=(3,1^13)`：存在大小 3 的模；
2. `h15_p00=(2,1^14)`：存在大小 2 的模。

如果两盒都 UNSAT，那么任何残余 K16 witness 必须是本原锦标赛。此前 \(h=11,12,13\) 中含多个 2/3 纤维的复合权型，对“是否存在任何可分解 witness”这一终点不必优先逐个重跑：它们若可行，本身已经含有大小 2 或 3 的模，必会落入上述两个对角结论之一。

## 五、目前可以安全写入论文的计算句子

> 对 16 点 Pisa 锦标赛的精确搜索已经排除了近正则层、两张最薄非近正则度谱，以及所有含大小至少 4 的非平凡模的候选。加权商审计对 \(h=3,\ldots,9\) 共核验 1,186,827,955 个强商/正权组合，零可行；随后 CP-SAT 完整关闭了 \(h=10\) 和单大纤维盒 \(h11\_p00,h12\_p00,h13\_p00\)。因此任何仍可能存在的 K16 Pisa 锦标赛，要么只由大小 2、3 的模组成，要么是本原锦标赛；同时它必须落在 \((7,1),B\ge16\) 或 \((6,3),B\ge20\) 的高阻塞 endpoint。

不能写：

- “K16 已证明不存在”；
- “所有 \(h=11,\ldots,15\) 商都已排除”；
- “v14 已排除了某个固定百分比的全部锦标赛”；
- “UNKNOWN 跑了一小时，所以大概率无解”。
